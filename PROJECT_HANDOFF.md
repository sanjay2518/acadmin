# ACAdmin / Wealcco Project Handoff

## 1. Project Purpose
This project is an accounting administration and client portal application.
It connects client organizations to Xero and displays accounting data.
Administrators can manage clients, users, connections, reports, and settings.
Clients can sign in to view their own portal and financial information.

## 4. Important Backend Areas
- Authentication and JWT helpers are near the beginning of `backend/main.py`.
- Admin client management is under the Admin section.
- Xero OAuth routes are under the Xero OAuth section.
- Xero access tokens are stored per client in `xero_connections`.
- OAuth state values are stored in `oauth_states`.
- Reports and dashboard data are fetched through Xero API helpers.
- PDF and Excel report generation is implemented in the backend.

## 5. Xero OAuth Details
- Connect route for clients: `/api/xero/connect`
- Connect route for admins: `/api/xero/connect/admin/{client_id}`
- Callback route: `/api/xero/callback`
- The callback must be registered exactly in the Xero Developer Portal.
- Local callback normally uses `https://acadmin-seven.vercel.app/api/xero/callback`.
- Production callback normally uses the deployed backend URL plus `/api/xero/callback`.
- `backend/main.py` resolves the callback from the incoming request host.
- Never commit Xero client secrets, Supabase keys, or JWT secrets.
